## `aneupy.geometry`

```text
SALOME layer: sections, shells and solids built with the GEOM module.

This is the only module that imports SALOME. Run it inside a SALOME environment, for
example with ``salome shell -- python3 script.py``.

Conventions
-----------
Lengths are in millimetres. A section is defined in the XY plane of its local coordinate
system (LCS), given by an origin and by local X and Y axes in global coordinates; its
normal is the local Z axis. The seam of a circle lies on the local X axis. Geometric
tolerances are in model units.
```

### class `Shell`

```text
Surface through a sequence of circular sections, closed by end caps.

Two surface methods are available:

* ``"thru_sections"`` (default) uses GEOM's ``MakeThruSections``, which builds a smooth
  NURBS surface through the sections. It was the most robust method in our tests.
* ``"filling"`` uses GEOM's ``MakeFilling``, the method of earlier versions. With
  ``approximation=True``, GEOM samples each section and fits a C2 non-rational B-spline
  surface to the grid of points. This fit is sensitive to the number of sections and
  can fail far from them, which the volume check of
  :meth:`Domain.add_solid_from_shell` detects.

Parameters
----------
name : str
    Shell name.
sections : sequence of Section
    At least two sections with circles, in axial order.
folder : bool, optional
    If true, group the entities in a folder of the study.
closed : bool, optional
    If true, sew the first and last section faces as end caps.
method : {"thru_sections", "filling"}, optional
    Surface method.
precision : float, optional
    3D precision of ``"thru_sections"``.
min_degree, max_degree : int, optional
    Range of the surface degree of ``"filling"``.
approximation : bool, optional
    Use GEOM's approximation algorithm in ``"filling"``. When true, GEOM ignores
    ``tol_2d`` and ``max_iterations``.
tol_2d, tol_3d : float, optional
    Tolerances of ``"filling"``.
max_iterations : int, optional
    Iterations of ``"filling"`` when ``approximation`` is false.
sewing_precision : float, optional
    Sewing tolerance of the end caps.
```

## `aneupy.pipelines`

```text
Reusable building blocks and ready-made model pipelines.

A pipeline is a sequence of plain function calls on a :class:`aneupy.geometry.Domain`:
describe each boundary as a list of :class:`Station`, loft it into a solid with
:func:`add_lofted_solid`, and combine solids with Boolean cuts. The ready-made builders
below follow that pattern and can be copied or replaced. See
``examples/custom_pipeline.py``.

The functions accept any object with the ``Domain`` interface and do not import SALOME.
```

### class `IdealizedParameters`

```text
Dimensional parameters of an idealized aneurysm.

An idealized model has a straight reference axis along global Z, circular
cross-sections, equal necks, uniform wall layers, and a sac centred at mid-length. Section
centres may be offset from the axis inside the sac. The shape is prescribed by these
parameters and it does not derive from an individual patient.

Parameters
----------
length : float
    Total model length in mm, including both necks.
radius_nondilated : float
    Lumen radius of the necks in mm.
radius_dilated : float
    Lumen radius at the sac midsection in mm, before any thrombus is added.
wall_thickness_intima, wall_thickness_media, wall_thickness_adventitia : float
    Layer thicknesses in mm.
ilt_thickness : float
    Intraluminal thrombus thickness at the sac midsection in mm. Zero means no
    thrombus.
x_shift, y_shift : float
    Offset of the sac midsection centre from the Z axis in mm. Zero means symmetry.
sac_fraction : float
    Aneurysm length as a fraction of ``length``.
section_spacing : float
    Axial distance between cross-sections in mm.

Notes
-----
Radius, thrombus thickness and centre shift all follow the shape function of
:meth:`sac_weight`, so ``D_max``, ``L_AAA``, ``r`` and ``R`` hold exactly at the
prescribed sections.
```


### `smoothing_weight(spacing, cutoff_length, order=SMOOTHING_ORDER)`

```text
Return the penalty weight whose half-gain wavelength is ``cutoff_length``.

The smoother of :func:`smooth_uniform` has the interior transfer function
``1 / (1 + weight * (2 sin(pi spacing / wavelength)) ** (2 * order))``.
```

### `smooth_uniform(values, spacing, cutoff_length, order=SMOOTHING_ORDER)`

```text
Smooth uniformly sampled data by penalized least squares.

Minimizes ``||z - y||^2 + weight ||D z||^2``, where ``D`` is the difference matrix of
the given ``order`` (Whittaker smoother). Oscillations with wavelength
``cutoff_length`` keep half of their amplitude, shorter ones are attenuated more,
and polynomials of degree below ``order`` are preserved exactly.

Parameters
----------
values : array_like
    Samples, with one or two dimensions (filtered along the first axis).
spacing : float
    Sample spacing in millimetres.
cutoff_length : float
    Half-gain wavelength in millimetres. Zero returns a copy of the input.
order : int, optional
    Order of the difference penalty.

Returns
-------
numpy.ndarray
    Smoothed samples.
```

### `check_tube_curvature(curvature, radii, name='section')`

```text

Parameters

name : str, optional
    Name used in messages.

Returns
-------

    The maximum of ``kappa * r``.

Raises
------
GeometryError
    If ``kappa * r >= 1`` at any station.
```

### `expected_loft_volume(centers, normals, radii)`

```text
Return the volume enclosed by a smooth loft through circular sections.

The axial coordinate advances by the projection of each step between centres on the

run with or against their normals, but all in the same sense.

Parameters
----------

    Section centres and unit normals.
radii : array_like, shape (n,)
    Section radii.

Returns
-------
float
    Volume in cubic millimetres.
```

